一个添加了个人创意的 Mindustry 模组（`v159.7+`），提供多种实用方块与便捷功能。

## 方块与物品

| 方块 | 说明 |
|------|------|
| 矿物转换器 | 按地图矿点稀有度，把可开采的矿物相互转化 |
| 物品传输中枢 | 零缓冲物流网络：按需拉取、盈余自动推送至核心，可跨中枢级联 |
| 电力保护器 | 电网崩溃时锁定电量并进入保护，记录消耗电力后在恢复模式下逐步偿还 |
| 利滚利发电机 | 按已存电力的 1%/秒复合产出电力，产出随电网状态自适应 |
| 发电泵 | 抽水同时消耗水发电 |
| 两用交叉器 | 传送带 / 导管两用的交叉路口 |
| 万向交叉器 | 1×1 物品交叉器：全局设置输出优先级应用到所有输入方向，可按方向单独覆盖；内置模板一键应用（均分/全右/主右备左/上下直通）、可手动保存自定义模板（0~4，数值越大越优先，同优先级轮流均分，0 不输出），50 物品/秒，点击方块在配置面板中直接设置 |
| 信号源 | 放置后生成唯一 4 位信号（如 A1G4），通电时信号有效；供维度锚点等设备配对使用 |
| 维度锚点 | 3×3 跨图物品传输：发送/接收两种模式，按信号配对；发送模式充能 10 秒后把库存整体发送给同信号接收锚点，同一信号仅允许一个接收锚点 |
| 开关 | 控制指向方块的启用/禁用 |
| 电力源 | 沙盒无限电源（与电网内其他电力源平分产出） |

## 功能

- **方块搜索**：建造菜单内跨全分类搜索方块，支持中文拼音模糊匹配（全拼/首字母）、搜索历史记录；
- **多人暂停**：多人游戏中可申请暂停，支持关闭/仅管理员/自定义白名单三种模式；
- **自动更新**：主界面自动检测 GitHub 新版本并弹窗提示，支持游戏内下载安装到模组目录后一键重启。

## 设置

进入游戏后：`设置 → Silicon设置`。

| 设置 | 说明 |
|------|------|
| 显示搜索历史 | 是否在方块搜索栏中显示最近搜索（可游戏内即时开关） |
| 选择后清除输入 | 从搜索结果选择方块后是否清空搜索输入 |
| 暂停模式 | 多人暂停权限：关闭 / 仅管理员 / 自定义（聊天命令 `!pause grant <玩家名>`） |
| 暂停请求 | 启用后按下暂停键向服务器发送暂停申请 |
| 管理暂停白名单 | 打开自定义暂停模式的白名单管理对话框 |
| 检查更新 | 立即向 GitHub 重新检查一次更新（有更新弹窗提示，已最新则提示） |

## 构建与固化验证

依赖 Mindustry `v159.7` 的 jar 与 **JDK 17**（Android 端 d8 需要）：

```powershell
# 一条龙：17 项代码锚点检查 → 编译 deploy → 自动同步游戏模组目录
powershell -ExecutionPolicy Bypass -File scripts\hub-deep-check.ps1

# 仅桌面快速构建
.\gradlew.bat jar
```

安装：把构建出的 `Silicon.jar` 放入游戏的 `mods` 目录（客户端：`%APPDATA%/Mindustry/mods`）后启动游戏。

## 开发流程（固化）

1. 修改代码后先跑单元测试（`tests/` 下三个套件，javac 直接编译运行，不依赖 Mindustry 运行时）
2. 运行 `scripts/hub-deep-check.ps1`：任一锚点 FAIL 即阻断；通过则自动 deploy 并把最新 jar 同步到 `%APPDATA%\Mindustry\mods\Silicon.jar`
3. 重启游戏实测
4. 版本号按 AGENTS.md 规范 bump，commit 格式 `[版本] 类型: 描述`
